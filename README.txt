# Romantic Website — CapCut/Reel-inspired

Open `index.html` in a browser.

## Replace the placeholders
- Change `YOUR PHOTO` blocks into your own photos.
- Change `Song One`, etc. to the songs you want.
- Edit the letter in `index.html`.
- Edit the 10 things list.
- The floral background is already included in `assets/pink-flowers.png`.

## Publish
Upload the folder to GitHub Pages, Netlify, Vercel, or any static hosting service.
